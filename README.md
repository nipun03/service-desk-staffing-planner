# Service desk staffing planner

Estimate how many agents an hourly queue needs to answer 80% of calls within 20 seconds.

Open index.html locally, or serve this directory as a static site. No installation or backend is required. For GitHub Pages, publish the repository root from the main branch.

Erlang C assumes steady arrivals, independent service times, and callers who stay in queue. Shrinkage covers time away from the queue. The default inputs are illustrative.

[Try the live demo](https://nipun03.github.io/portfolio/projects/staffing-planner/index.html)
